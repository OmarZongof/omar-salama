# Omar Salama — Portfolio

Personal portfolio site. Plain HTML, CSS and JavaScript — no build step.

## Publish free on GitHub Pages

1. Create a GitHub account (if you don't have one) at github.com.
2. Click **New repository**. Name it exactly `YOUR-USERNAME.github.io` (replace with your GitHub username), set it to **Public**, and create it.
3. On the repository page click **Add file → Upload files**. Drag in everything from this folder: `index.html`, `README.md` and the whole `assets` folder. Click **Commit changes**.
4. Go to **Settings → Pages**. Under "Build and deployment" choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
5. Wait 1–2 minutes. Your site is live at `https://YOUR-USERNAME.github.io`.

To update the site later, upload the changed files again in the same way.

## Things to edit

- **GitHub icon:** open `index.html`, search for `GITHUB_URL` near the bottom and paste your profile link, e.g. `"https://github.com/omarsalama"`. The icon stays hidden until you do.
- **Résumé:** replace `assets/Omar_Salama_Resume.pdf` with your latest version (same file name).
- **Certificates:** images live in `assets/certs/`.
- **Months counter:** calculated automatically from your SirApp start date (13 Jun 2025).

## Optional: custom domain

Buy a domain (e.g. omarsalama.dev), add it under **Settings → Pages → Custom domain**, and follow GitHub's DNS instructions.
